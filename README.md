# Data-Mirror
📌 Data Mirror：看見你的數位足跡

🧭 Project Overview

Data Mirror is an open-source project that aims to make digital rights and data privacy more accessible and understandable to the general public.

In today’s digital environment, users constantly generate data through everyday actions such as browsing, messaging, and using mobile applications. However, the processes behind data collection, analysis, and usage often remain invisible.

This project seeks to “mirror” these invisible processes and transform them into something visible, relatable, and understandable.

💡 Why this project?

As a software engineer, I have been involved in system design where data security and privacy are critical considerations. Through this experience, I began to realize that technical decisions are not only about performance or efficiency, but also deeply connected to users' digital rights.

At the same time, I noticed a gap:

1. Technical knowledge is often inaccessible to non-technical users

2. Discussions about digital rights rarely reach the general public

Data Mirror is an attempt to bridge this gap.

🎯 What does it do?

Users input their daily digital behaviors, such as:

1.Social media usage

2.Location services

3.Online shopping


The system then:

1.Maps possible data being collected

2.Visualizes a “digital footprint profile”

3.Highlights potential privacy risks


🌍 Project Goals

1.Make digital rights more understandable

2.Translate technical concepts into human-centered knowledge

3.Support digital literacy education

4.Encourage reflection on personal data usage


🧩 Future Development
